# Predictive Input — Android 64-bit

Proyecto de compilación para Geometry Dash 2.2091 en Android ARM64 con Geode v6.0.0-alpha.2.

## Compilar
1. Abre la pestaña **Actions**.
2. Selecciona **Build Predictive Input (Android64)**.
3. Pulsa **Run workflow**.
4. Al terminar, descarga el artefacto **PredictiveInput-Android64**.

El flujo obtiene el código fuente GPL-3.0 del proyecto original, aplica la configuración Android y compila un artefacto de prueba. El offset Android está basado en la biblioteca `libcocos2dcpp.so` que se revisó para este proyecto; no garantiza compatibilidad con todas las instalaciones del juego.

**Importante:** la compilación debe pasar y probarse en el teléfono antes de considerar el mod funcional. No es un mod verificado ni una versión oficial.
