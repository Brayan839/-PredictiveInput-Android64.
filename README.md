# Predictive Input — Android 64-bit

Configuración de compilación para Geometry Dash 2.2091 en Android ARM64 con **Geode v6.0.0-beta.2**.

## Compilar
1. Abre la pestaña **Actions**.
2. Selecciona **Build Predictive Input (Android64)**.
3. Pulsa **Run workflow**.
4. Cuando termine correctamente, descarga el artefacto **PredictiveInput-Android64-Beta2**.

El flujo compila el código fuente del proyecto original y aplica la configuración Android. El offset Android configurado corresponde a la biblioteca `libcocos2dcpp.so` que se revisó anteriormente; no garantiza compatibilidad con todas las instalaciones.

**Importante:** el cambio a beta.2 está configurado, pero el mod todavía debe compilarse y probarse en el teléfono antes de considerarlo funcional.
